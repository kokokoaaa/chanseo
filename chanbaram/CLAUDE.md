# 찬바람 — 작업 규칙

롤 칼바람(증강 모드)을 참고한 3대3 한 다리 증강 난투. 게임은 `chanbaram/index.html` 한 파일. 찬서(`../index.html`)와 별개 게임이지만 같은 저장소·같은 배포(GitHub Pages `main`)를 쓴다. 주소: https://kokokoaaa.github.io/chanseo/chanbaram/

## 소통·배포
- 사용자와는 항상 한국어. 수정 후 결과를 짧게 정리하고 확인용 파일(`찬바람_vN.html`)을 보낸다.
- 패치마다 `const BUILD=숫자`를 1 올린다 (자동 업데이트 기준).
- 사용자가 **"배포해"** 라고 할 때만 `main`에 올린다 (찬서와 같은 절차: `git push origin <작업브랜치>:main`). 찬서 쪽 미배포 변경이 섞이지 않는지 확인한다.

## 원칙
- 롤의 시스템은 그대로 참고하되 **이름·문구·그림은 전부 새로** 만든다 (챔피언·스킬·아이템·증강 이름에 롤 고유 이름 금지).
- 기본은 싱글(나 + 봇 2 vs 봇 3). 실시간 대전은 나중에 방장 P2P(WebRTC) + Apps Script 연결 방식으로.
- 이모지는 유니코드 11 이하만 (🧊 🩸 🪓 🦣 🪄 등 12 이상 금지).
- 증강·아이템 id는 겹치면 안 된다.

## 테스트
- `node --check`(스크립트 추출), Playwright로 `window.__CB`(startGame(id,true)=자동 플레이, step)로 봇끼리 여러 판 끝까지 돌려 오류·판 길이(목표 15~20분)·직업별 성적 확인.
- 화면은 메뉴 → 챔피언 선택 → 증강 → 상점 → 실제 판 스크린샷으로 확인.
